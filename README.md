# 12-DOF Quadruped Robot Dog

## Overview

This project presents a 12-Degree-of-Freedom (12-DOF) Quadruped Robot Dog designed to demonstrate stable locomotion, gait coordination, and embedded robotic control. The robot utilizes four legs with three servo-actuated joints per leg, enabling smooth and coordinated movement across various surfaces.

The project integrates mechanical design, electronics, and software to create a versatile robotic platform for learning and experimentation in robotics, mechatronics, motion control, and autonomous systems.

## Features

* 12 Degrees of Freedom (3 DOF per leg)
* Stable quadruped locomotion
* Forward, backward, left, and right movement
* Coordinated gait generation
* Servo motor-based actuation
* Embedded control system
* Modular and scalable design
* Suitable for robotics research and education

## Working Principle

The robot achieves movement through coordinated control of twelve servo motors distributed across its four legs. Gait algorithms generate synchronized leg motions, allowing the robot to walk, turn, and maintain balance. The controller calculates and sends position commands to each servo motor, resulting in smooth locomotion and stable operation.
